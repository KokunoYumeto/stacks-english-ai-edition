# Verified Stacks errata candidate

This candidate records fourteen independently proved source corrections against
Stacks Project commit `a04446e57ec1fbc252a871afcec7752fb2807b14` (tree
`3feeb703b931a6e7259782c10e7d1575adc83e5e`). It is an independently
maintained, AI-produced candidate. The Stacks Project authors and maintainers
have not requested, reviewed, approved, or endorsed it.

The payload contains only:

- five bounded corrections in `smoothing.tex`;
- one bounded correction in `crystalline.tex`;
- seven bounded corrections in `spaces-cohomology.tex`; and
- nine permanent-tag records generated by the frozen source tree's own tag
  allocator for nine live labels missing from `tags/tags`.

The unmodified authority bytes, producer reports, canon verification ledger,
allocator implementation, exact source-to-payload map, decisions, rejections,
mechanical checks, build receipts, and replay evidence are retained beside the
payload. The upstream source remains governed by its own GNU Free Documentation
License 1.2; the exact licence bytes are in `authority/COPYING`.

One inherited proposal, `MC-STK-ERR-0004`, was removed after proof review: the
printed “there exists … that” construction is grammatical and semantically
valid, so changing it to “such that” would be style editing rather than errata.
The rejection remains append-only in the canon and candidate ledgers.

This directory is a candidate namespace under lease
`stacks-lease-000004-errata`. A lease is not admission. Until a separate
receipt-bound admission transition is completed, none of these corrections is
part of a registered overlay or release.

Canonical CJK translations remain faithful to the frozen upstream bytes. They
do not silently incorporate this payload and do not render erratum notes.
